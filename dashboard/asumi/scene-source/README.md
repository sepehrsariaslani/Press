# شخصیت و روایت سه‌بعدی آسومی

مدل اختصاصی با الهام از فرم نرم و کارتونی مرجع کاربر؛ لباس سبز مریم‌گلی،
صندلی کرم، موی قهوه‌ای و نور گرم. هیچ مدل یا بافت شخص ثالث استفاده نشده است.

- `asumi-office.blend`: فایل قابل ویرایش در بلندر؛ شش حالت در فریم‌های ۱ تا ۱۲۱.
- `create_office.py`: ساخت مجدد مدل، انیمیشن، خروجی وب و تصویر جایگزین.
- `../src/story/`: متن مراحل، کنترل اسکرول، صحنه و حرکت اسناد در پوشه‌های مستقل.

ساخت مجدد دارایی‌ها با بلندر ۵.۲:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python scene-source/create_office.py
```

سپس از پوشه‌ی `dashboard/asumi`:

```sh
COREPACK_ENABLE_AUTO_PIN=0 yarn test --run
COREPACK_ENABLE_AUTO_PIN=0 yarn build
```

این تغییر فقط نمای معرفی است و به مهاجرت دیتابیس نیاز ندارد. دکمه‌ی ورود به
مسیر موجود `/hesab` می‌رود. اعداد، هشدار و مراحل خودکار صحنه، داده‌های نمایشی‌اند
و عملیات واقعی روی اسناد حسابداری انجام نمی‌دهند.

صفحه از اسکرول طبیعی، متن HTML فارسی، پیوند مستقیم به هر مرحله، کاهش حرکت،
بارگذاری جداگانه‌ی صحنه، سقف تراکم پیکسل و نمایش تصویر در صورت خطای سه‌بعدی
استفاده می‌کند. هیچ حلقه‌ی دائمی برای حرکت خودکار پس‌زمینه وجود ندارد.
